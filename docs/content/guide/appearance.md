# 見た目の調整

## テーマのカスタマイズ

デフォルトテーマはバイナリに埋め込まれており、プロジェクトの `theme/` に
**同じ相対パスのファイルを置くだけ**でファイル単位に上書きできます
（テンプレート・CSS・JS のどれでも）。

> [!IMPORTANT]
> 上書きしたファイルは、yuzu を更新したときに**デフォルトテーマ側の変更へ追随する
> 責任が利用者側にあります**。テンプレートに渡す変数・生成するアセット・JS が
> 期待する DOM は、版ごとに変わることがあります（例: `syntect.css` は
> `markdown.highlight.enabled` が有効なときだけ生成され、`base.jinja` も
> `highlight_enabled` で `<link>` を出し分けます。古い `base.jinja` を
> 上書きしたまま無効化すると、存在しないファイルへの `<link>` が残ります）。
> 上書きは必要なファイルだけに絞り、更新後は差分を見直してください。

色だけ変えたい場合は、設定の CSS 変数上書きが手軽です:

```toml
[theme.css_vars]
accent = "#0a6cff"

[theme.css_vars_dark] # ダークモード時のみの上書き
accent = "#7fb2ff"
```

## ダークモード

ダークモードの扱いは `theme.dark` で選びます。

| 値 | 切替ボタン | 表示 |
| --- | --- | --- |
| `"toggle"`（既定） | 出す | ボタンで選んだ配色。選んでいなければ OS の設定に従う |
| `"auto"` | 出さない | OS の設定に従う |
| `"light"` | 出さない | 常にライト |

OS の設定に従うのは CSS（`prefers-color-scheme`）なので、JavaScript が無効でも
効き、OS 側でライト / ダークを切り替えるとその場で追従します。ボタンで選んだ配色は
ブラウザに保存され、次に開いたときも同じになります。v0.18 までの `dark = true` は
`"toggle"`、`dark = false` は `"light"` として読みます（見た目は変わりません）。

## 印刷と PDF

ブラウザの印刷（「PDF に保存」）が、そのまま配布できる紙面になるよう
デフォルトテーマが調整してあります:

- サイドバー・目次・検索・コピーボタン等の画面用 UI は紙に載りません
  （パンくずと最終更新日は残ります）
- ダークモードで表示していても、印刷は常にライト配色です
  （本文・コードハイライト・ビルド時に SVG にした図とも）
- 閉じた折りたたみとタブは全展開されます（タブはラベルを小見出しにして縦に並びます）
- 表はページをまたぐと見出し行が再掲され、コードは横に切れず折り返します
- 外部リンクは URL が括弧書きで併記されます

テーマを `theme/static/css/theme.css` で丸ごと上書きしている場合は、
この印刷対応も上書き側の内容に従います。

> [!NOTE]
> 図をブラウザで描く既定の設定（`[markdown.mermaid]` の `backend = "client"`）では、
> ダークモードのまま印刷すると図だけ暗い配色で紙に載ります（mermaid.js が描いた
> 時点の色を図に書き込むため）。印刷前にライトへ切り替えるか、`backend = "ssr"` に
> してください（ビルド時に作る図はテーマの配色に従うので、自動でライトになります）。
> 選び方は[図（Mermaid）](diagrams.md#client-と-ssr-の選び方)を参照してください。
